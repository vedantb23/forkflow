  📎 SETUP: Cloudinary (image storage)

  What it is: a free hosted service that stores images and gives you back a URL.
  We upload restaurant/menu photos there so our DB only stores a small URL
  string, never image bytes.

  1. Go to https://cloudinary.com → Sign up (free tier is plenty)
  2. After login you land on the Dashboard — you'll see three values: Cloud 
  name, API Key, API Secret (click the eye icon to reveal the secret)
  3. Paste them into backend/.env:
  CLOUDINARY_CLOUD_NAME=your_cloud_name
  CLOUDINARY_API_KEY=your_key
  CLOUDINARY_API_SECRET=your_secret

  Then install the two packages we need (from backend/):
  npm i cloudinary multer && npm i -D @types/multer
  What they do: cloudinary = the official SDK to upload images from our server.
  multer = Express middleware that parses multipart/form-data (how browsers send
  file uploads) and hands us the file buffer. Success = both appear in
  package.json, no red errors.

  Tell me "done" when the keys are in .env and the install finished, and I'll
  start building the restaurants module.
